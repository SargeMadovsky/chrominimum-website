Философия ChroMinimum

Всё необходимое.
Ничего сверх того.

Первый прототип намеренно ограничен базовыми возможностями браузера. Меньше элементов интерфейса — меньше отвлекающих факторов.

▣

Одно окно

Никаких вкладок в первом прототипе. Только текущая страница и пространство для её содержимого.

↔

Базовая навигация

Адресная строка, назад и вперёд, обновление и остановка загрузки. Ctrl+L и F5 тоже работают.

⌘

Современный движок

Chromium Embedded Framework обеспечивает отображение сайтов, JavaScript и PDF без необходимости создавать веб-движок с нуля.

{ }

Rust в основе

Нативная оболочка разрабатывается на Rust с использованием CEF. Исходный код проекта доступен на GitHub.

◌

Минимум интерфейса

В начальной версии нет пользовательских плагинов, сложной панели инструментов и управления множеством вкладок.

◇

Экспериментальный подход

Цель — снизить накладные расходы оболочки без отключения защитных механизмов ради скорости. Проверка преимуществ продолжается.

Предварительные измерения

Не маркетинговые обещания. Измерения.

20 октября 2026 года проведены локальные тесты запуска на Windows: по 10 успешных прогонов с одной тестовой страницей. Это ранние результаты конкретных сборок, а не доказательство превосходства над другими браузерами на реальных сайтах.

Версии Chromium различались, нагрузка системы не была полностью изолирована; на старых компьютерах тестирование ещё не проводилось.

Все релизы ↗

Чего пока нет

  • Полноценного менеджера загрузок и завершённой системы разрешений.
  • Вкладок и пользовательских расширений в текущем прототипе.
  • Независимого аудита безопасности и доказанного ускорения на реальных сайтах.
  • Нотарификации приложения для macOS.

Подробные планы и технические решения представлены отдельно от уже реализованных возможностей.
